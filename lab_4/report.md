# Лабораторная работа 4

## Алгоритмы отсечения отрезков и многоугольников

## Цель работы

Изучить методы отсечения отрезков и многоугольников и реализовать их визуализацию на координатной плоскости.

## Задание

Создать веб-приложение с координатной сеткой, отсекающим окном, исходными объектами и видимыми после отсечения частями. Для прямоугольного окна реализовать алгоритмы Сазерленда-Коэна, Лианга-Барски и средней точки. Для второй части реализовать отсечение отрезков выпуклым многоугольником и отсечение выпуклого многоугольника.

## Реализация

Приложение находится в `lab_4/index.html`. Пользователь выбирает часть работы и алгоритм, задает прямоугольное окно, координаты отрезка, масштаб и выпуклые многоугольники. Отрезок можно добавить числовыми полями или провести указателем на рабочем поле.

Исходные отрезки рисуются серой пунктирной линией, прямоугольное окно и отсекающий многоугольник выделяются фиолетовым цветом, видимые части объектов выводятся более толстой цветной линией. В интерфейсе присутствуют сетка, оси, подписи, легенда, список объектов и журнал вычислений.

В алгоритме Сазерленда-Коэна для каждой конечной точки формируется четырехбитный код области: `LEFT = 1`, `RIGHT = 2`, `BOTTOM = 4`, `TOP = 8`. Нулевые коды означают принятие отрезка, ненулевое побитовое И кодов - отклонение. В алгоритме Лианга-Барски строится параметрическое представление отрезка и определяется интервал параметра `t`. Алгоритм средней точки находит границы видимого интервала последовательным делением.

Для отсечения отрезка выпуклым многоугольником реализован алгоритм Кируса-Бека. Направление обхода вершин определяется по знаку площади многоугольника. Для отсечения выпуклого многоугольника используется алгоритм Сазерленда-Ходжмана: исходная фигура последовательно обрабатывается относительно каждой грани отсекателя.

## Проверка работы

Встроенный пример использует окно `X = [-90, 90]`, `Y = [-55, 55]` и пять отрезков. Для первого отрезка от `(-150, -90)` до `(150, 95)` видимая часть имеет границы приблизительно `(-90, -53)` и `(85.1, 55)`. Отрезок, полностью расположенный внутри окна, остается без изменений. Отрезок, лежащий снаружи одной области, отклоняется. Такие случаи позволяют проверить принятие, частичное отсечение и полное отклонение.

В режимах второй части можно задать выпуклый отсекатель и произвольные исходные данные. Программа выводит результат отсечения и ход алгоритма для последнего добавленного отрезка или для многоугольника.

## Вывод

Разработано интерактивное приложение для визуализации алгоритмов отсечения. Реализованы три алгоритма для прямоугольного окна, алгоритм Кируса-Бека и алгоритм Сазерленда-Ходжмана. Интерфейс позволяет наблюдать исходные объекты, результат отсечения и промежуточные вычисления.
