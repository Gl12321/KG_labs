# Лабораторная работа 1

## Цветовые модели CMYK RGB HLS

## Цель работы

Изучить представление цвета в моделях RGB, HLS и CMYK, а также реализовать интерактивное преобразование между ними.

## Задание

Разработать веб-приложение, в котором цвет задается из палитры, числовыми полями и ползунками. При изменении любого параметра остальные представления цвета должны пересчитываться автоматически. Для нечетного варианта используется набор моделей CMYK, RGB и HLS.

## Краткие сведения

В модели RGB цвет задается интенсивностями красного, зеленого и синего каналов в диапазоне от 0 до 255. Модель HLS описывает оттенок H в градусах от 0 до 360, светлоту L и насыщенность S в процентах. В полиграфической модели CMYK используются доли голубой C, пурпурной M, желтой Y и черной K красок.

Для перехода из RGB в CMYK компоненты сначала нормализуются к диапазону от 0 до 1. Значение черной компоненты вычисляется по формуле `K = 1 - max(R, G, B)`. При `K < 1` остальные компоненты находятся как `C = (1 - R - K)/(1 - K)`, `M = (1 - G - K)/(1 - K)` и `Y = (1 - B - K)/(1 - K)`.

При вычислении HLS используются максимальная и минимальная нормализованные компоненты RGB. Светлота равна `(max + min)/2`, а оттенок определяется по каналу с максимальным значением. Для обратного перехода используется вспомогательная функция преобразования оттенка в компоненту RGB.

## Реализация

Приложение находится в файле `lab_1/index.html`. В интерфейсе размещены три панели с параметрами RGB, HLS и CMYK, круговой образец цвета, палитра и шестнадцатеричное представление выбранного цвета.

Состояние цвета хранится в RGB. Реализованы функции `rgbToHls`, `hlsToRgb`, `rgbToCmyk` и `cmykToRgb`. После каждого изменения вызывается функция отображения, которая пересчитывает модели, обновляет поля, ползунки, подписи, образец и HEX-код. Значения HLS и CMYK задаются с точностью до сотых, что позволяет плавно изменять цвет.

Обработчики события `input` установлены для всех числовых полей и ползунков. Обработчик палитры разбирает выбранный HEX-код и обновляет RGB-состояние. За счет этого любой способ задания цвета ведет к одному результату во всех трех моделях.

## Проверка работы

Проверены следующие сценарии.

1. При вводе RGB `(255, 0, 0)` приложение выводит HEX `#FF0000`, HLS с `L = 50` и CMYK со значением `M = 100`.
2. При задании HLS `(120, 50, 100)` получается зеленый цвет `#00FF00`.
3. При задании CMYK `(100, 0, 100, 0)` получается тот же зеленый цвет `#00FF00`.
4. При выборе `#123456` из палитры поля RGB получают значения `18`, `52` и `86`.

## Вывод

Разработано веб-приложение для интерактивной работы с цветовыми моделями CMYK, RGB и HLS. Цвет можно задавать тремя способами в каждой модели, а все связанные представления пересчитываются автоматически.
