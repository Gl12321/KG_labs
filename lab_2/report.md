# Лабораторная работа 2

## Локальная пороговая обработка изображений

## Цель работы

Освоить методы локальной пороговой обработки и сравнить их поведение на изображениях с неоднородным фоном, шумом и низким контрастом.

## Задание

Реализовать два метода локальной пороговой обработки, обеспечить графический интерфейс, загрузку собственного изображения и набор тестовых изображений.

## Краткие сведения

Локальная пороговая обработка формирует порог для каждого пикселя отдельно. Порог зависит от яркости в окрестности пикселя, поэтому метод лучше глобального порога работает при неравномерном освещении и меняющемся фоне.

В первом методе используется локальное среднее: `T = mean - C`, где `mean` - средняя яркость в окне, а `C` - настраиваемая константа. Во втором методе учитывается разброс яркостей: `T = mean + k * std`, где `std` - локальное стандартное отклонение, а `k` - коэффициент. Пиксели с яркостью выше порога окрашиваются в белый цвет, остальные - в черный.

## Реализация

Приложение реализовано в `lab_2/index.html`. Пользователь может загрузить изображение или выбрать один из четырех тестовых вариантов: градиент с шумом, низкоконтрастное изображение, размытый текст и фон с пятнами. Исходное изображение и результат выводятся рядом на двух холстах canvas.

Яркость пикселя вычисляется как среднее значений R, G и B. При выходе окна за границы изображения координаты ограничиваются ближайшим допустимым пикселем. Радиус окна, константа C и коэффициент k задаются в интерфейсе. После обработки выводятся размер окна, время выполнения и имя выбранного метода.

В коде выделены функции `localMeanThreshold` и `localMeanStdThreshold`. Каждая из них возвращает новый массив пикселей, поэтому исходное изображение остается доступным для повторной обработки с другими параметрами.

## Проверка работы

Для проверки предусмотрены изображения с разными свойствами. На градиенте с шумом можно оценить устойчивость порога к изменениям освещения. На низкоконтрастном примере видна роль константы C. Для размытого текста метод со стандартным отклонением позволяет менять порог в участках с разной локальной контрастностью. Изображение с пятнами показывает преимущество локального порога перед единым значением для всего кадра.

Первый метод проще и использует только среднюю яркость в окне. Второй метод дополнительно учитывает стандартное отклонение, поэтому чувствительнее к структуре локальной области. Параметры подбираются по виду изображения и требуемой детализации результата.

## Вывод

Реализованы два метода локальной бинаризации, загрузка пользовательских изображений и набор тестовых примеров. Интерфейс позволяет изменять параметры и сразу сравнивать исходное изображение с результатом обработки.
