# Лабораторная работа 3

## Базовые растровые алгоритмы

## Цель работы

Изучить основные алгоритмы растеризации отрезков и окружностей, реализовать их визуализацию на дискретной сетке и измерение времени выполнения.

## Задание

Создать веб-приложение, иллюстрирующее пошаговый алгоритм, алгоритм ЦДА, алгоритм Брезенхема для отрезка и алгоритм Брезенхема для окружности. В интерфейсе должны быть система координат, оси, сетка, масштаб, подписи и вывод времени работы.

## Реализация

Приложение находится в `lab_3/index.html`. Пользователь выбирает алгоритм, вводит координаты концов отрезка или радиус окружности, задает масштаб и запускает построение. Рабочая область представляет собой canvas размером 800 на 600 пикселей.

Координаты математической плоскости переводятся в координаты canvas по формулам `Xc = ox + x * scale` и `Yc = oy - y * scale`, где `(ox, oy)` - центр холста. Перед построением выводятся оси, линии сетки и числовые подписи. Каждый растровый элемент привязан к целочисленной сетке с помощью округления координат.

Пошаговый алгоритм и ЦДА вычисляют число шагов как `max(|dx|, |dy|)`, после чего последовательно добавляют приращения по X и Y. Алгоритм Брезенхема для отрезка использует ошибку `err = |dx| - |dy|` и целочисленные поправки координат. Алгоритм Брезенхема для окружности строит восемь симметричных точек и изменяет решающий параметр `d`.

После запуска фиксируются отметки `performance.now()`, поэтому время работы показывается в миллисекундах для текущего браузера и текущего набора данных. Журнал в интерфейсе содержит последовательность построенных точек.

## Пример расчета

Встроенный пример использует алгоритм Брезенхема для отрезка от `(10, 10)` до `(50, 30)`. Для него `dx = 40`, `dy = 20`, направления по обеим осям положительные, начальная ошибка равна `20`. На каждом шаге выбирается следующая точка по сравнению удвоенной ошибки с `-dy` и `dx`. Приложение выводит эти значения и все полученные пиксели в журнале.

## Проверка работы

Проверяются четыре режима построения: произвольный отрезок пошаговым алгоритмом, тот же отрезок алгоритмом ЦДА, отрезок алгоритмом Брезенхема и окружность заданного радиуса. Для каждого режима доступны очистка холста, изменение масштаба и повторный запуск. Интерфейс отображает число шагов и измеренное время.

## Вывод

Реализованы четыре базовых алгоритма растеризации. Приложение показывает связь между целочисленными координатами и пикселями canvas, визуализирует сетку и выводит журнал вычислений и время построения.
